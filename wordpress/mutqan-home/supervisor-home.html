مركز التعديل السريع

التغييرات محفوظة في قناة بيانات مشتركة باسم mutqan_home_config_v1. هذه النسخة التجريبية تسمح للصفحة الرئيسية بقراءة التحديثات فورًا من نفس المتصفح.

عند تحويلها إلى WordPress، يتم استبدال قناة localStorage ببيانات إضافة MUTQAN/REST API مع صلاحيات المشرف.
